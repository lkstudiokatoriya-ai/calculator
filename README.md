## 📌 Project Overview

> **Note:** This project is currently in its **active early-stage (v1.0)**. While it handles everyday arithmetic seamlessly, it is actively evolving into a powerful scientific and engineering computational tool.

---

## ✨ Current Features (v1.0)

- [x] **Core Arithmetic Operations:** Instant Addition (`+`), Subtraction (`-`), Multiplication (`×`), and Division (`÷`).
- [x] **Smart Entry Controls:** 
  - `AC` (All Clear) & `DEL` (Backspace for single-character correction)
  - Decimal support with input validation
  - Percentage calculation (`%`)
- [x] **Responsive & Modern UI:** Glassmorphism-inspired button layout optimized for mobile and desktop viewports.
- [x] **Real-Time Output:** Instant visual updates with zero calculation lag.

---

## 🚀 Upcoming Roadmap (In Active Development)

- [ ] **Scientific Mode:**
  - Trigonometric functions (`sin`, `cos`, `tan`, and inverses)
  - Logarithmic calculations (`log`, `ln`)
  - Powers, roots, and factorials ($x^y$, $\sqrt{x}$, $n!$)
  - Math constants ($\pi$, $e$)
- [ ] **Calculation History Log:** View, re-use, and export past computations.
- [ ] **Keyboard Accessibility:** Complete hotkey mapping for lightning-fast typing.
